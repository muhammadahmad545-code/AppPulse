# AppPulse — Store listing draft

## Short description

Know Where Your Time Goes. Offline screen-time tracking for Android.

## Full description

AppPulse helps you understand how you spend time on your phone — fully offline.

Track every app, explore timelines and analytics, set limits with smart reminders, run focus sessions, and export reports. No account. No cloud. No ads.

Features:
- Live dashboard with charts and trends
- Installed apps list with search, sort, favorites, and pins
- Detailed per-app history and yearly charts
- Timeline with flexible date filters
- Analytics: categories, heatmaps, dayparts
- App limits with notify / overlay / full-screen reminder styles
- Focus mode with apps to avoid
- PDF / CSV / JSON reports via the share sheet
- Local backup and restore

Permissions explained in-app:
- Usage Access — required to read on-device usage stats
- Notifications — optional limit / focus alerts
- Display over other apps — optional system overlay reminders
- Battery optimization — optional for more reliable background sync
